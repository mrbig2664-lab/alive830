# ALIVE V4 · Room Zero

Clean-room interactive ALIVE V4 preview for the OPPO Find N6 Folded/Unfolded display.

The app is a static browser experience. Daily records, mood, check-in, settlement,
Nurture, Plant/Egg progression, and Undo are stored locally in IndexedDB with a
localStorage fallback.

## Run locally

```bash
npm run dev
```

Open `http://localhost:4173/` and switch between Folded and Unfolded from the header.
